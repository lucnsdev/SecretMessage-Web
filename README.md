# SecretMessage

Um sistema que faz uso do Firebase Cloud Messaging e RealTime Database para enviar e armazenar mensagens anônimas, em tempo real, para um app android.

Repositório do app: [SecretMessage-App](https://github.com/lucnsdev/SecretMessage-App)

Pagina Web hospedada: https://lucns-secret.freedev.app/
